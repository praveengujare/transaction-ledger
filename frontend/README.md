# Transaction Ledger — React Frontend

## Requirements
- Node.js 18+
- Backend running at `http://localhost:8080`
- MySQL database configured in the backend

## Run
```bash
npm install
npm run dev
```
Open `http://localhost:5173`.

Optional: copy `.env.example` to `.env` and set `VITE_API_BASE_URL`.
The frontend uses the REST endpoints implemented by the backend ZIP.
